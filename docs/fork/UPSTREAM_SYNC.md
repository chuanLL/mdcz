### 部署前必须核对的行为变化

新增的 `jellyfin.useProxy` 和 `emby.useProxy` 默认 `false`。旧版本在全局代理开启时经代理访问远程媒体服务器，升级后默认会改成直连。部署前须逐项确认远程服务器是否依赖代理，需要时显式开启对应开关；不能直接用旧配置启动后假定连接方式完全不变。本次未更改任何生产配置。

该开关允许公网媒体服务器使用现有全局代理，不强制代理局域网地址。局域网判定按 URL 中的 IP/主机名进行，不查询 DNS，也不保证自动重定向链逐跳重新选择代理；私有 DNS 域名、带尾点的域名及特殊网络拓扑需单独验收。长 Cookie 会话的代理切换缓存与真实 Cookie 交换未做设备联调。

维护分支可包含这项回移，但上述行为核对和设备同层验证仍是今后部署的前置工作。
